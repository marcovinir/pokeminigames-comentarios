# PokeMiniGames: ideas y errores

Aquí se reciben los comentarios de [PokeMiniGames](https://pokemon-minigames.onrender.com), minijuegos Pokémon para jugar 1 vs 1 con tus amigos.

- **¿Tienes una idea?** [Abre una idea](../../issues/new?template=idea.yml).
- **¿Algo falla?** [Avisa de un error](../../issues/new?template=error.yml).

Las issues son **públicas**: no pongas tu correo, tu contraseña ni otros datos personales.
Para borrar tu cuenta no hace falta escribir aquí: entra en tu perfil y usa «Borrar mi cuenta».

Proyecto de fans sin fines de lucro. Pokémon y sus personajes son marcas de Nintendo, Game Freak y The Pokémon Company; no hay relación con ellos.
